## 产品体验建议（不是已验证故障）

1. 首页提供“完成定位→收集一份素材→生成第一篇草稿”的下一步入口，而不是让新人猜模块顺序。
2. 内容创作收敛为编辑、检查、确认三个阶段；Hook、去 AI 感等专业词附短说明。
3. 发布中心明确为辅助复制发布而非自动发布；平台版本目前只读（src/main.tsx:1673），建议允许保存平台专属修改，并提供发布记录入口。
4. 注册页补充内测数据用途、反馈/找回账号路径；是否限制邀请码由用户决定，不自行改注册政策。
