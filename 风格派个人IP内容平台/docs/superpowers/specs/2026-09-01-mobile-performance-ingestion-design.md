# 阶段三：移动端内容数据解析设计

- 依赖：统一内容资产跨端闭环设计、三 API 配置中心
- 入口：今日待拍文案
- 模型：API 3 专用视觉模型

## 行为

用户将待拍文案标记为已发布，上传一张或多张平台后台截图。服务端通过 API 3 识别平台和指标，生成候选结果并匹配文案。低置信度字段突出显示；无法可靠匹配时进入待匹配列表。用户确认或修正后创建新的内容表现快照。

API 3 未配置或调用失败时保留截图，支持重试和手动填写。图片不得发送给 API 1 或 API 2。

## 验收

手机可打开今日待拍文案、上传多图、预览候选指标、人工修正和确认；确认前不写正式数据；确认后可追溯原图、原始模型结果、修正字段和历史快照。
