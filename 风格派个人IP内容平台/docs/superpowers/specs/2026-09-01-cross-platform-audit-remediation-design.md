# 跨端功能审计阻断项修复设计

**日期：** 2026-09-01  
**作者：** Monkeycode  
**状态：** 已确认

## 目标

修复跨端内容资产任务 9、12、13 的验收缺口，使桌面文件夹同步、手机截图解析人工确认和同一文案表现历史成为真实可操作功能，而不只是服务端接口或状态展示。

## 设计原则

- 网页与 Electron 均可登记目录；只有目标 Electron 设备负责验证路径和实际监听。
- 离线设备允许预登记目录，未验证前不得进入同步队列。
- 截图解析结果必须由用户人工确认后才能创建正式表现快照。
- 表现快照只追加、不覆盖；缺失指标保持 `null`。
- 渲染进程不获得 Node.js、文件系统、Cookie 或其他会话凭据。

## 一、Electron 桌面同步

### 架构

Electron 主进程负责文件系统能力，预加载脚本只暴露白名单 IPC。桌面端登录后从服务端读取当前账号设备和同步目录配置，匹配当前 `device_id`，逐项验证路径并管理监听器。

### 配置状态

同步目录使用以下可观察状态：

- `pending_verification`：网页或离线状态下登记，尚未由目标设备验证。
- `watching`：路径存在、有读取权限且监听器已启动。
- `paused`：用户暂停，不监听、不入队。
- `path_missing`：目标路径不存在。
- `permission_denied`：无读取权限。
- `offline`：目标设备未上线。

未处于 `watching` 的目录不得提交文件事件。

### IPC 边界

新增白名单能力：

- 选择本地文件夹。
- 获取本机设备标识与同步运行状态。
- 立即刷新服务端目录配置。
- 对已验证目录执行立即扫描。

预加载脚本只传递结构化结果；不暴露通用 IPC、任意路径读取或会话 Cookie。

### 队列

文件监听继续使用稳定等待、相对路径合并、SHA-256 和 Base64 清单。队列持久化到 Electron 用户数据目录；联网后提交，成功项移除，失败项保留并展示原因。

## 二、截图解析人工确认

### 入口

人工确认流程放在“今日拍摄”对应条目内。上传截图后，条目展示任务状态并允许刷新或重试。

### 内容

待确认卡展示：

- 原始截图预览、补充和删除。
- 候选文案、匹配依据与置信度。
- 平台及各项解析指标。
- 低置信度提示。
- 用户可编辑的指标值。
- 删除任务、重试和“确认并存入表现”操作。

只有确认接口成功后才刷新正式表现历史。失败任务持续保留错误，不静默移除。

## 三、表现历史

每个已发布拍摄条目提供可展开的表现时间线，按抓取时间倒序显示：

- 抓取时间和发布后天数。
- 平台。
- 播放、点赞、评论、收藏、转发等实际存在指标。
- 与前一次快照的增量；缺失值显示“未提供”，不按零计算。
- 数据来源和确认状态。

历史数据从现有表现快照查询接口读取，不新增覆盖更新接口。

## 四、前端结构

避免继续扩大单一组件职责，新增三个聚焦组件：

- `DesktopSyncPanel`：目录配置、设备状态和桌面运行状态。
- `VisionConfirmationCard`：任务状态、截图、候选匹配和人工确认。
- `PerformanceTimeline`：快照历史和增量展示。

组件继续使用现有账号鉴权 API，不自行存储凭据。

## 五、错误处理

- 网页登记离线设备目录时明确显示“等待设备验证”。
- 路径不存在和权限不足分别展示，不归并为通用失败。
- 视觉 API 未配置、调用失败或解析结果无效均保留任务和具体错误。
- 网络中断时桌面队列保留；恢复后允许自动或手动重试。
- 所有账号级资源继续执行所有权过滤，跨账号返回 404 或空结果。

## 六、测试与验收

必须补齐以下自动化测试：

1. IPC 仍为严格白名单，渲染进程不能任意访问文件系统。
2. 网页可为离线设备预登记目录，未验证目录不入同步队列。
3. Electron 验证路径后启动监听；暂停、恢复、删除同步生效。
4. 稳定文件事件进入持久队列，失败项保留并可重试。
5. 前端可读取视觉任务候选、修改指标并调用人工确认接口。
6. 未确认任务不创建快照，确认后只追加一条快照。
7. 同一文案多次快照按时间展示，缺失指标保持未提供。
8. 跨账号目录、截图任务和表现快照均不可访问。
9. `npm run verify`、核心 E2E、Electron 安全测试和 Windows 目录打包通过。

## 非目标

- 不建立独立的全局表现中心。
- 不允许浏览器直接访问或监听本地文件系统。
- 不新增后台常驻 Windows 服务。
- 不修改现有品牌视觉体系和无关业务模块。
