# 基础 IP 档案字段编辑设计

日期：2026-08-31
状态：已确认

## 目标

允许用户在“已确认基础档案”中直接修改单个字段。用户主动修改视为已确认事实，保存后立即用于内容生成；未来系统提取的信息仍进入待审核区。

## 交互

- 每个基础字段提供独立“编辑”按钮。
- 身份定位、核心定位语使用文本输入；列表字段使用多行输入，每行或顿号分隔一项。
- 编辑状态提供“保存”和“取消”；一次只编辑一个字段。
- 保存成功后立即刷新当前字段并显示更新时间。
- 修改记录区域展示最近的字段、修改时间、修改前和修改后内容。

## 数据与接口

- 档案字段继续按现有边界保存：身份、受众、问题、支柱、观点、风格、边界写入 `/api/profile`；定位语、变现目标、获客路径写入 `/api/positioning`。
- 两个 PUT 接口继续使用局部字段合并，并新增 `version`、`history` 记录；每条历史包含字段名、修改前值、修改后值和时间。
- 不引入新的集合或数据库表，不改变待审核接口。

## 验收标准

- 任意基础字段可独立编辑、取消和保存。
- 保存后刷新页面仍保留修改结果，并立即成为 API 返回的当前档案。
- 每次保存生成版本记录，页面可查看最近修改。
- 空值不得覆盖已确认字段；列表输入会去除空项和首尾空格。
- `npm run verify` 通过。
