# 阶段二：Electron 本地文件夹同步设计

- 依赖：统一内容资产跨端闭环设计
- 平台：Windows
- 入口：Electron 桌面端

## 行为

用户登录后添加多个文件夹。Electron 持续监听 TXT、Markdown、Word、PDF、Excel 的新增和修改，等待文件稳定后以二进制安全方式上传服务端。服务端按账号、相对路径和校验值去重并解析，素材库显示来源和同步状态。

本地删除只记录源文件已删除，不删除云端素材。网络断开时队列落盘，恢复后继续；登录失效暂停并保留队列；解析失败提供重试。

## 验收

Windows 安装、登录、多文件夹管理、新增、修改、断网恢复、重复文件和删除保留云端全部通过；五类文件解析正确；敏感路径和 Key 不泄露。
