# IP 档案双区展示设计

日期：2026-08-31
状态：已确认

## 目标

让已确认的“小姚哥”基础 IP 档案直接成为工作台资料，同时保留未来访谈、素材和外部资料的增量审核入口。

## 页面结构

`IP 档案`页面拆为两个区域：

1. **已确认基础档案**：展示身份定位、定位语、服务对象、经营问题、内容支柱、核心观点、表达风格、表达边界、变现目标和获客路径，并标记来源与更新时间。
2. **待审核变更**：只展示 `pending` 状态的档案提取记录。没有待审核记录时显示空状态说明。

## 数据流

基础档案通过现有 `/api/profile` 与 `/api/positioning` 读取，直接用于后续内容生成。未来访谈、素材提取和外部资料进入现有 `/api/profile/reviews`，通过审核后调用现有审核接口增量合并，保留来源引用和版本信息。

## 兼容与边界

- 保持现有 API 路径和审核接口不变。
- 已确认、已拒绝记录不显示在待审核列表。
- 不覆盖已有已确认事实，不复制完整私密档案原文。
- 只修改 IP 档案页面及必要的测试，不调整研究、素材、选题和草稿数据。

## 验收标准

- IP 档案页面能看到“小姚哥｜创业过来人”的基础资料。
- 没有待审核记录时，待审核区显示明确空状态。
- 存在已确认或已拒绝记录时，它们不出现在待审核区。
- 既有审核通过流程仍可用。
- `npm run verify` 通过。
