# 跨端内容资产闭环实施计划

- [x] 1. 建立统一数据模型与存储边界
  - [x] 1.1 扩展素材来源、解析状态、源文件删除和设备字段，并完成旧数据默认值迁移
  - [x] 1.2 增加设备、同步文件夹、同步文件、私有文件、表现快照和截图解析任务模型
  - [x] 1.3 扩展 MySQL 集合存储、JSON 回退及按用户隔离逻辑
  - [x] 1.4 编写模型迁移、用户隔离、幂等和历史兼容测试

- [x] 2. 实现三 API 加密配置中心
  - [x] 2.1 实现 AES-256-GCM 服务端加密、掩码读取和密钥更新接口
  - [x] 2.2 将 API 1、API 2 定义为主备文本模型，将 API 3 定义为专用视觉模型
  - [x] 2.3 实现三套配置的独立连接测试、启停和能力验证
  - [x] 2.4 实现旧浏览器配置的用户确认迁移流程
  - [x] 2.5 编写加密往返、错误密钥、日志脱敏、文本主备和图片路由测试

- [x] 3. 建立私有文件存储与安全上传
  - [x] 3.1 实现按用户、日期和校验值组织的私有文件存储
  - [x] 3.2 实现文件名清洗、路径穿越防护、大小及 MIME 类型限制
  - [x] 3.3 实现鉴权预览、下载、校验值去重和文件元数据接口
  - [x] 3.4 编写恶意路径、伪造类型、重复文件和跨用户访问测试

- [x] 4. 完成热点研究手动收录素材
  - [x] 4.1 实现研究记录到 `hotspot` 素材的收录与来源追踪接口
  - [x] 4.2 实现按账号和研究来源幂等去重
  - [x] 4.3 在热点研究结果中增加“收录为素材/已收录”状态
  - [x] 4.4 在素材库展示热点来源、平台、原链接和研究记录
  - [x] 4.5 编写收录、重复收录、未收录隔离和来源追踪测试

- [x] 5. 检查点：确保阶段一及公共基础测试通过，如有疑问请询问用户

- [x] 6. 创建 Windows Electron 桌面应用
  - [x] 6.1 建立 Electron 主进程、渲染进程、预加载脚本和安全 IPC 边界
  - [x] 6.2 接入现有账号登录、会话刷新和退出
  - [x] 6.3 使用系统安全存储保存会话，不在渲染进程暴露凭据
  - [x] 6.4 实现托盘、开机启动、窗口关闭后后台运行和安全退出
  - [x] 6.5 编写 IPC 白名单、会话恢复和窗口生命周期测试

- [x] 7. 实现本地文件夹同步引擎
  - [x] 7.1 复用并改造 `desktop/sync-client.mjs`，支持多个目录和持久化队列
  - [x] 7.2 实现文件稳定检测、事件合并、断网恢复和登录失效暂停
  - [x] 7.3 将 TXT、Markdown、Word、PDF、Excel 改为二进制安全上传
  - [x] 7.4 实现新增、修改、重复和本地删除事件协议
  - [x] 7.5 本地删除仅标记 `source_deleted_at`，不删除云端素材
  - [x] 7.6 编写事件合并、校验值稳定性、队列恢复和删除保留属性测试

- [x] 8. 实现服务端文档解析流水线
  - [x] 8.1 为 TXT、Markdown、Word、PDF、Excel 建立独立解析适配器
  - [x] 8.2 实现等待、处理中、成功、失败和重试状态
  - [x] 8.3 将解析结果写入素材正文、候选主题、金句和来源引用
  - [x] 8.4 隔离单文件失败，避免阻断同步批次
  - [x] 8.5 为五类格式、损坏文件、超限文件和重试编写测试

- [x] 9. 完成 Electron 同步管理界面
  - [x] 9.1 实现文件夹添加、暂停、恢复、移除和立即同步
  - [x] 9.2 展示设备、队列、最后同步时间和逐文件状态
  - [x] 9.3 展示失败原因、重试入口和源文件已删除状态
  - [x] 9.4 在网页素材库展示来源设备、相对路径和同步状态
  - [x] 9.5 编写同步管理接口与桌面同步链路集成测试

- [x] 10. 检查点：确保 Electron、五类文档解析和素材库联动测试通过，如有疑问请询问用户

- [x] 11. 建立发布记录与内容表现模型
  - [x] 11.1 扩展今日待拍文案的已发布状态、平台和发布时间
  - [x] 11.2 实现表现快照、原始指标、修正字段、置信度和历史记录接口
  - [x] 11.3 缺失指标保持空值，禁止自动转换为零
  - [x] 11.4 编写快照追加、历史不可覆盖、空值保持和用户隔离测试

- [x] 12. 实现手机截图上传与 API 3 解析
  - [x] 12.1 在今日待拍文案中增加多图上传和解析任务入口
  - [x] 12.2 将截图保存至私有文件存储，并提示第三方视觉模型处理
  - [x] 12.3 仅调用 API 3，输出平台、指标、数值、置信度和原始模型结果
  - [x] 12.4 API 3 未配置或失败时保留任务，并提供重试和手动填写
  - [x] 12.5 编写 API 3 路由隔离、失败保留、多图任务和重复截图测试

- [x] 13. 实现文案匹配、人工确认与数据回填
  - [x] 13.1 根据平台、标题、发布日期生成候选文案及匹配依据
  - [x] 13.2 无可靠匹配时进入待匹配列表
  - [x] 13.3 实现低置信度提示、字段修改、删除、补充和截图预览
  - [x] 13.4 仅在用户确认后创建正式表现快照
  - [x] 13.5 增加表现历史查看和同一文案多次快照对比
  - [x] 13.6 编写候选匹配、确认门禁、人工修正和历史追加测试
