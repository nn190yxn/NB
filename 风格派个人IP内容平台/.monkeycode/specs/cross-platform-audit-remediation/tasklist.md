# 跨端功能审计阻断项实施计划

- [ ] 1. 补齐 Electron 本机同步运行能力
  - [ ] 1.1 扩展白名单 IPC 和预加载接口
    - 增加文件夹选择、设备信息、配置刷新和立即扫描能力。
    - 保持沙箱隔离，不暴露通用 IPC、Cookie 或任意文件读取。
  - [ ] 1.2 实现桌面同步协调器
    - 拉取当前设备目录配置，验证路径和权限。
    - 管理监听器的启动、暂停、恢复和销毁。
    - 写回 `pending_verification`、`watching`、`path_missing`、`permission_denied` 等状态。
  - [ ] 1.3 接入持久化同步队列
    - 文件稳定后生成 SHA-256/Base64 清单。
    - 合并重复路径事件，失败项保留并支持重试。
  - [ ] 1.4 编写 Electron IPC、目录验证、监听生命周期和离线队列测试

- [ ] 2. 完善同步配置服务端与前端
  - [ ] 2.1 扩展同步目录和设备状态模型
    - 支持离线设备预登记及目标设备绑定。
    - 未验证目录不得进入同步队列。
  - [ ] 2.2 完善网页和 Electron 同步管理面板
    - 网页可选择设备并登记路径。
    - Electron 可使用系统文件夹选择器。
    - 展示验证状态、队列、逐文件结果及失败原因。
  - [ ] 2.3 编写账号隔离、离线预登记和状态转换测试

- [ ] 3. 检查点
  - [ ] 3.1 确保 Electron 安全测试和同步专项测试通过，如有疑问请询问用户

- [ ] 4. 实现截图解析人工确认闭环
  - [ ] 4.1 抽离 `VisionConfirmationCard`
    - 展示任务状态、候选文案、匹配依据、置信度和解析指标。
    - 支持重试、补图、删图及原始截图预览。
  - [ ] 4.2 实现指标编辑和确认提交
    - 低置信度字段明确提示。
    - 只有确认成功后创建正式表现快照。
    - API 失败时保留任务、修正值和错误信息。
  - [ ] 4.3 编写候选匹配、人工修正、确认门禁和跨账号隔离测试

- [ ] 5. 实现表现快照时间线
  - [ ] 5.1 抽离 `PerformanceTimeline`
    - 按时间倒序显示同一文案的全部快照。
    - 展示发布后天数、平台、指标及相邻快照增量。
    - 缺失指标显示“未提供”，不按零计算。
  - [ ] 5.2 将时间线接入今日拍摄条目
    - 确认新快照后立即刷新历史。
    - 保持旧快照不可覆盖。
  - [ ] 5.3 编写多快照追加、排序、增量和空值语义测试

- [ ] 6. 完成审计质量门
  - [ ] 6.1 补齐热点→素材→创作→发布→截图确认→表现历史自动化 E2E
  - [ ] 6.2 运行全量测试、类型检查、生产构建和 Electron 打包
  - [ ] 6.3 扫描前端响应、日志和构建产物，确认 API 密钥未泄露
  - [ ] 6.4 更新任务清单、架构、接口、开发文档和项目 README
