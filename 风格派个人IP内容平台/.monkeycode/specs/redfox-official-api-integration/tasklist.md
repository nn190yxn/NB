- [ ] 1. 重构 RedFox 官方 API 适配器
  - 修改 `server/redfox.mjs`，将默认 `/v1/*` 路径替换为官网真实 Host/Path 映射。
  - 统一使用官网要求的 `POST`/`GET`、`REDFOX_API_KEY` 或 `X-API-KEY` 鉴权和 JSON 请求体。
  - 增加官网响应 `{ code: 2000, data }` 的解析与现有工作台结构归一化；禁止凭猜测兼容不存在的旧路径。
  - 实现聚合热点、关键词热搜、小红书热门账号及官网文档确认的搜索/合规接口映射。
  - 保留无配置演示数据和既有错误代码语义。
  - [ ] 1.1 为每个官网接口补充请求 Method、Path、请求体和成功响应归一化测试
  - [ ] 1.2 增加非 JSON、空响应、非 2000 成功码、401/403、429 和 5xx 的错误测试
  - [ ] 1.3 增加请求体/响应字段的属性测试，确保任意合法官网数据不会泄露 Key 且输出符合现有边界

- [ ] 2. 修正服务端研究路由与连接测试

  - 确保研究搜索、热点刷新、热搜榜、相似/合规调用全部复用官方适配器，不从浏览器接收明文 Key。
  - 保留账号隔离、服务端 AES-256-GCM、演示兜底和正式调用启用状态约束。
  - [ ] 2.1 更新 API 路由集成测试，断言官方 URL、Method、Headers、JSON body 和 `code: 2000` 处理
  - [ ] 2.2 增加不同账号不可读取或使用他人 RedFox 配置的回归测试
  - [ ] 2.3 增加上游错误映射和日志脱敏测试

- [ ] 3. 更新前端连接测试与错误展示契约
